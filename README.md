# Soundcheck

브라우저에서만 돌아가는 음악 시각화/분석 페이지. 외부 API도, 서버도, 빌드 단계도 없다.
`index.html` 하나가 전부이므로 GitHub Pages에 그대로 올라간다.

## 두 가지 보기

**Letters** — 입력한 글자 수 `N`만큼 가청 대역(42 Hz–14 kHz)을 옥타브 균등하게(로그 간격)
쪼개고, 글자 하나가 한 대역의 레벨 막대 역할을 한다. 글자는 `scaleY`로 늘어나고 피크 홀드
선이 글자 끝에 맞춰 따라붙는다. 글자 아래에는 그 대역의 중심 주파수가 찍힌다.
재생할 음원이 없으면 페이지가 직접 합성한 104 BPM 루프(킥·베이스·하이햇·코드 스탭)를 쓴다.

대역을 선형이 아니라 로그로 나누는 게 핵심이다. 음악 에너지는 저역에 몰려 있어서 선형으로
나누면 글자 대부분이 에너지가 거의 없는 고역을 맡아 왼쪽 몇 글자만 움직인다. 표시 감도는
관측된 피크를 따라가는 오토게인으로 맞추므로 조용한 곡도 화면을 다 쓴다.

**Library** — 음원 파일을 올리면 곡마다 측정값을 뽑아 비교한다.

| 측정값 | 정의 |
|---|---|
| RMS dBFS | 전체 프레임 RMS 적분. **LUFS가 아니고** K-weighting도 없으므로 상대 비교용 |
| 크레스트 dB | `20·log10(peak/RMS)`. 작을수록 세게 압축된 마스터 |
| 밝기 Hz | 프레임별 spectral centroid를 프레임 에너지로 가중 평균 |
| BPM (est.) | 스펙트럼 플럭스 → 온셋 곡선 → 자기상관 피크 (포물선 보간) |
| 대역 균형 | 저역 <250 Hz / 중역 250 Hz–2 kHz / 고역 >2 kHz 에너지 비율 |

## 신호 처리

모노 합산 후 22.05 kHz로 리샘플 → Hann 창 1024, 홉 512(≈43 프레임/초) → FFT.
FFT는 radix-2 Cooley–Tukey를 직접 구현했고(라이브러리 없음), 분석은 Web Worker에서 돌아
긴 곡을 넣어도 UI가 멈추지 않는다. 디코딩은 `OfflineAudioContext`로 리샘플하고, 실패하면
라이브 컨텍스트 디코딩 + 선형보간 데시메이션으로 떨어진다.

템포는 자기상관 피크를 온셋 곡선 에너지로 정규화한 값이 0.12 미만이면 숫자 대신 `—`를
낸다. 주기적 온셋이 없는 자료(드론, 지속음)에 없는 템포를 만들어내지 않기 위한 장치다.

## 검산

페이지를 처음 열면 핑크 노이즈·킥 루프·하이햇 루프를 직접 합성해 같은 분석기에 통과시킨다.
분석기가 멀쩡한지 매번 확인하는 용도다. 알려진 입력에 대한 기대값:

| 입력 | 기대 | 실측 |
|---|---|---|
| 1 kHz 사인파 | centroid 1000 Hz, 크레스트 3.01 dB | 1000 Hz, 3.0 dB |
| 킥 루프 100 BPM | 저역 지배, BPM 100 | 저역 99.8%, 124 Hz, 99.8 BPM |
| 하이햇 루프 100 BPM | 고역 지배, BPM 100 | 고역 99.1%, 7.0 kHz, 99.6 BPM |
| 1 kHz 사인파 (템포) | 비트 없음 → 거부 | `—` (conf 0.000) |

## 한계

- RMS는 물리량이다. 지각 라우드니스를 보려면 K-weighting(ITU-R BS.1770)이나
  A-weighting으로 바꿔야 한다.
- 템포 추정은 4/4 균일 박자를 가정한다. 하프타임, 루바토, 변박에서 틀린다.
- 밝기(centroid) 하나로는 음색을 설명하지 못한다. rolloff, flatness, MFCC가 빠져 있다.
- 대역 경계 250 Hz / 2 kHz는 관행적인 값이고 지각적 임계대역(Bark, ERB)이 아니다.

## 띄우기

```bash
python3 -m http.server 8000
# http://localhost:8000
```

`file://`로 바로 열어도 대부분 동작하지만, Library 탭의 Web Worker가 막히는 브라우저가
있으므로 위처럼 HTTP로 띄우는 쪽이 확실하다. GitHub Pages는 저장소 Settings → Pages에서
브랜치 `main` / 경로 `/`를 지정하면 끝이다.
