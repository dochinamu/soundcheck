# Soundcheck

글자가 스펙트럼 막대 역할을 하는 음악 비주얼라이저. 브라우저에서만 돌아가고 서버도,
빌드 단계도, 외부 음원 파일도 없다. `index.html` 하나가 전부다.

**데모: https://dochinamu.github.io/soundcheck/**

## 무엇을 하나

입력한 글자 수 `N`만큼 가청 대역(42 Hz–14 kHz)을 쪼개고, 글자 하나가 한 대역의 레벨
막대가 된다. `SOUNDCHECK`이면 10글자이므로 10개 대역이고, 왼쪽 `S`가 베이스, 오른쪽 `K`가
심벌을 맡는다. 글자 아래에는 그 대역의 중심 주파수가 찍힌다.

## 작동 방식

**대역 분할.** 선형이 아니라 **옥타브가 균등해지는 로그 간격**으로 나눈다. 이게 핵심이다.
음악 에너지는 저역에 몰려 있어서 선형으로 나누면 오른쪽 글자 대부분이 에너지가 거의 없는
고역을 맡아 멈춰 있게 된다. 대역 경계는 `f_k = 42 · (14000/42)^(k/N)`, 중심은 양 끝의
기하평균이다.

**레벨.** `AnalyserNode`를 FFT 4096(≈11 Hz 해상도), `smoothingTimeConstant` 0.6으로 두고
각 대역에 속한 빈들의 평균을 낸다. 고역일수록 에너지가 적으므로 대역 번호에 비례하는 틸트
(`1 + 0.9·k/(N-1)`)를 곱해 보정한다.

**표시.** 붙을 때는 즉시, 떨어질 때는 프레임당 14%씩 천천히 움직여 타격이 눈에 남는다.
피크 홀드 선은 글자가 늘어나는 것과 같은 배율(`1 + v·1.55`)로 계산해 글자 끝에 정확히
붙는다. 감도는 관측된 피크를 따라가는 오토게인이 맞추므로 조용한 곡도 화면을 다 쓴다.

**데모 루프.** 음원이 없어도 바로 보이도록 104 BPM 4마디(킥·베이스·하이햇·코드 스탭)를
`AudioBuffer`에 직접 합성한다. 킥은 지수 감쇠 주파수 스윕, 하이햇은 1차 차분으로 밝게
만든 노이즈 버스트다.

## 띄우기

```bash
python3 -m http.server 8000
# http://localhost:8000
```

GitHub Pages는 Settings → Pages에서 브랜치 `main` / 경로 `/`를 지정하면 끝이다.

## 한계

- 대역 경계는 로그 균등일 뿐 지각적 임계대역(Bark, ERB)이 아니다. 멜 스케일로 바꾸면
  사람이 느끼는 음높이 간격에 더 가까워진다.
- `AnalyserNode`의 바이트 스펙트럼(0–255)을 쓰므로 정밀도가 8비트로 제한된다. 정량 분석이
  아니라 표시용이라 충분하다고 보고 택한 선택.
- 틸트 보정 계수는 귀로 맞춘 값이다. 장르별 평균 스펙트럼 기울기로 적합하면 더 정확해진다.
